# The-Soul-System
A modular Paper plugin adding an optional Souls progression system. Players earn persistent UUID-based Soul balances from configurable PvE ***** with optional PvP, protected by cooldowns and diminishing returns. Every 100th Soul grants stacking 0.** boosts to Haste, Strength, Speed, and Absorption up to a 500 cap. Includes Soul Fragments via PersistentDataContainer convertible at configurable rates, /souls commands with top and pay features, admin give/take/set/inspect/reload, toggleable Soul Shop, Altar, Powers, Bounties, Shrines, and random Events. Configurable death loss, per-world settings, PlaceholderAPI support, SQLite default with optional MySQL/MariaDB, async storage, event-driven performance, exploit protection, and SoulEarn/SoulSpend/SoulLose API events.
